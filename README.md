## 혼자 하기 (컴퓨터 상대)
모든 게임은 설정 화면에서 **🤖 혼자 (컴퓨터와)** 를 고르면 1인으로 플레이할 수 있고, 컴퓨터 난이도(쉬움/보통/어려움)를 선택합니다. 사람끼리 하려면 **👥 여럿이서** 를 고르세요.

| 게임 | 쉬움 | 보통 | 어려움 |
|---|---|---|---|
| 마법의 미로 | 벽을 절반만 기억하고 가끔 엉뚱하게 움직임 | 벽을 대부분 기억 | 벽을 모두 기억하고 위험을 계산해 이동 |
| 벽바둑 | 무작위 수가 많음 | 현재 판의 영역을 계산해 한 수 앞을 봄 | 상대의 응수까지 읽음 |
