## 혼자 하기 (컴퓨터 상대)
모든 게임은 설정 화면에서 **🤖 혼자 (컴퓨터와)** 를 고르면 1인으로 플레이할 수 있고, 컴퓨터 난이도(쉬움/보통/어려움)를 선택합니다. 사람끼리 하려면 **👥 여럿이서** 를 고르세요.

| 게임 | 쉬움 | 보통 | 어려움 |
|---|---|---|---|
| 마법의 미로 | 벽을 절반만 기억하고 가끔 엉뚱하게 움직임 | 벽을 대부분 기억 | 벽을 모두 기억하고 위험을 계산해 이동 |
| 벽바둑 | 무작위 수가 많음 | 현재 판의 영역을 계산해 한 수 앞을 봄 | 상대의 응수까지 읽음 |
| 장기 | 1수 앞, 실수 잦음 | 3수 앞 탐색 | 6수 앞 탐색(알파-베타) |
| 바둑 | 따내기·단수·세력을 보지만 실수가 많음 | 따내기·단수 방어·세력을 고려해 최선수 | 상대 응수까지 읽음 |
| 오목 | 가끔 엉뚱한 곳에 둠 | 내 공격과 상대 위협을 점수로 계산 | 상대의 반격(4·열린3)을 한 수 앞서 읽음 |

> 장기: 빅장(왕끼리 마주 봄)은 둘 수 없게 단순화했고, 400수가 넘으면 기물 점수로 승부합니다. 바둑: 한국식 계가(집+사석), 덤 9줄 7집·13/19줄 7.5집, 대국이 끝나면 죽은 돌을 컴퓨터가 추정하고 직접 고칠 수 있어요.

## 온라인 대전 (벽바둑)
설정 화면에서 **🌐 온라인**을 고르면 방 목록이 나옵니다. 방을 만들고(선택: 비밀번호), 입장한 사람이 모두 **준비**를 누르면 3초 뒤 시작해요. 카운트 중 누군가 준비를 해제하면 취소됩니다.

**서버 설정 (한 번만)**: Firebase Realtime Database를 만들고 `firebase-config.js`의 `BG_DB_URL`에 데이터베이스 주소를 넣으면 켜집니다. 비어 있으면 온라인 모드는 "서버 설정 필요"로 표시되고 나머지 모드는 그대로 동작해요.

## 앱으로 설치 (PWA)
GitHub Pages 주소를 크롬/삼성 인터넷에서 열고 **홈 화면에 추가**(또는 설치)를 누르면 **보드게임즈** 앱이 생기고, 실행 시 전체화면으로 열립니다. 오프라인에서도 혼자 하기/여럿이서 모드는 동작해요. 푸시하면 다음 실행 때 최신 버전으로 갱신됩니다.
