# 마법의 미로 (Magic Labyrinth)

보이지 않는 벽을 기억해 마법 심볼을 모으는 보드게임 *The Magic Labyrinth*의 웹 버전 프로토타입입니다. (2~4인, 한 기기 돌려 하기)

## 플레이
▶ https://kjt7942.github.io/boardGames/magic-labyrinth/

## 로컬 실행
`index.html`을 브라우저로 열면 됩니다. 빌드가 필요 없습니다.

## 규칙 요약
- 6x6 미로, 숨은 벽은 매 판 랜덤 생성 (쉬움 18 / 보통 24 / 어려움 25개)
- 주사위(1·2·2·3·3·4)만큼 상하좌우로 이동, 벽에 부딪히면 시작 모서리로 복귀
- 찾는 심볼 칸에 도착하면 획득, 5개를 먼저 모으면 승리

## 혼자 하기
설정에서 **🤖 혼자 (컴퓨터와)** 를 고르면 컴퓨터(쉬움/보통/어려움)와 1인으로 즐길 수 있어요.
