# 벽바둑 (Wall Go)

넷플릭스 「데블스 플랜: 데스룸」에 나온 벽바둑의 웹 버전입니다. (2~3인, 한 기기 돌려 하기, 태블릿을 바닥에 놓고 둘러앉는 레이아웃)

## 플레이
▶ https://kjt7942.github.io/boardGames/wall-go/

## 규칙 요약
- 7×7 판. 2인은 말 4개(2개는 미리 배치), 3인은 말 2개씩
- 매 턴: 말 하나를 상하좌우 0~2칸 이동 → 그 말이 있는 칸의 한 면에 벽을 반드시 설치
- 벽은 모두에게 적용. 한 사람의 말만 있는 구역이 그 사람의 영역
- 모든 구역에 한 사람의 말만 남으면 종료, 영역 칸 수가 가장 큰 사람이 승리
- 3인전은 1인 1회 '벽 부수기'

※ 2인 시작 위치, 동점 처리 등은 공개 자료를 바탕으로 한 추정입니다.
